# Studio Borne

The website for Studio Borne, a London social media strategy and content creation agency.
Next.js 16, deployed by Vercel from `main`.

```
npm install
npx next dev -p 3001
```

Then open http://localhost:3001. Use port 3001, not 3000 (see `HANDOVER.md`).

Checks: `npx eslint .`, `npx tsc --noEmit`, `npx next build`.

`HANDOVER.md` has how the site is built, the owner's design rules and the open items.
